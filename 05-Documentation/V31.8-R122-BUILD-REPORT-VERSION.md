# R122 — version du rapport d'environnement de build

Auteur : Abdelhalim Talbi. Version produit : V31.8.

## Défaut corrigé

`Application/windows/build-environment-report.ps1` publiait la valeur constante `18.6`, incompatible avec `VERSION.txt` et les artefacts V31.8. Le rapport pouvait donc induire en erreur lors d'un diagnostic de machine de build.

## Changement

Le script résout la racine du dépôt depuis son propre chemin et lit `VERSION.txt`. Il refuse de produire un rapport si le fichier est absent, illisible ou ne contient pas une version canonique `major.minor`. Le champ JSON `version` est dérivé de cette valeur, sans duplication d'une version applicative dans le script. La détection d'Inno Setup utilise également la syntaxe PowerShell explicite pour la variable d'environnement `ProgramFiles(x86)`.

Le rapport reste en lecture seule : il n'ouvre aucune connexion réseau, ne lit aucun identifiant et n'exporte aucun chemin de profil utilisateur.

## Tests et gates

`Application/tests/test_build_environment_report_r122.py` vérifie le contrat source et, lorsque PowerShell est disponible, exécute le script dans un dépôt temporaire avec une version alternative, sans `VERSION.txt`, puis avec une valeur malformée. La CI Windows est la qualification dynamique autoritative. La lane Linux/OpenSSH ne revendique que le contrôle source si PowerShell n'est pas installé ; elle ne simule pas l'exécution PowerShell.

Les trois lanes Windows native, OpenSSH/SFTP réel et ZIP cumulatif doivent passer sur le SHA final R122 avant toute qualification de release. La construction cumulée doit fournir installateur/portable réels et manifestes vérifiés avant qu'un ZIP soit annoncé comme qualifié.

## Limites

Aucune interface n'a changé, donc aucune capture R122 n'est requise ou revendiquée. Ce correctif n'améliore pas la parité des douze outils et ne modifie aucun statut : couverture globale actuelle **10 PARTIAL / 2 NOT_IMPLEMENTED / 0 IMPLEMENTED**. Aucune connexion d'entreprise, aucun secret ni déploiement distant n'est utilisé.
