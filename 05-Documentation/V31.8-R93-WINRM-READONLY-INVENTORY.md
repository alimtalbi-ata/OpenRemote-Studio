# OpenRemote Studio V31.8 — R93 : inventaire Windows WinRM en lecture seule

**Auteur : Abdelhalim Talbi.** Date : 24 octobre 2026. Statut : première brique backend **PARTIAL**, sans interface Qt ni qualification sur serveur Windows réel.

## Besoin et architecture

Première couverture du cas Windows Admin Center : afficher l'identité de l'OS Windows Server et les volumes locaux, sans pouvoir lancer de commande arbitraire. Le module Application/winrm_readonly.py expose WinRMReadOnly(origin, username, credential_provider, timeout=30) et inventory(online=False, cancelled=None).

Chemin de contrôle : opérateur -> opt-in online=True -> fournisseur d'identifiants à l'exécution -> origine HTTPS stricte -> pywinrm (optionnel) -> unique script PowerShell constant Get-CimInstance (Win32_OperatingSystem, Win32_LogicalDisk DriveType=3) -> validation JSON bornée -> objets normalisés. Aucun accès réseau à l'import, aucun fallback HTTP, aucune commande d'administration, aucune persistance de mot de passe.

## Sécurité et garde-fous

- HTTPS uniquement, origine sans chemin, paramètres, fragment ni userinfo ; port 5986 par défaut. Certificat TLS vérifié (server_cert_validation='validate'), transport NTLM explicite.
- Fournisseur de mot de passe **appelé uniquement après** consentement online=True ; pas de mot de passe dans l'URL, les scripts, les logs ou les erreurs.
- Script PowerShell fixe, sans interpolation d'hôte, de compte, d'identifiant ou de données utilisateur ; aucune API d'exécution arbitraire.
- Requêtes bornées (15–60 secondes), réponse maximale 64 Kio, au plus 128 volumes, tailles et noms validés ; rejet intégral si sortie inattendue.
- Codes d'erreur fermés ; jamais de message d'exception de transport, de stderr PowerShell ni de réponse brute. L'annulation est vérifiée avant et après l'appel ; elle ne peut pas interrompre une opération pywinrm déjà en cours.
- Pas de stockage des secrets ni de capture automatique. Une intégration avec le coffre doit fournir un callback éphémère et gérer la révocation.

## Usage d'intégration (exemple non exécuté sur serveur réel)

    from winrm_readonly import WinRMReadOnly
    client = WinRMReadOnly('https://srv-lab.example.test:5986', 'DOMAIN\\reader',
                           credential_provider=secret_provider)
    preview = client.inventory()  # offline, aucun appel
    result = client.inventory(online=True)  # opt-in explicite

secret_provider est un callback applicatif non fourni par ce module. L'exemple est illustratif, pas une preuve de connexion. Pour l'accès réel, installer séparément la dépendance optionnelle pywinrm dans un environnement maîtrisé, fournir un compte de lecture adapté et un certificat serveur validé. Ne jamais désactiver la validation TLS pour « faire fonctionner » un lab.
