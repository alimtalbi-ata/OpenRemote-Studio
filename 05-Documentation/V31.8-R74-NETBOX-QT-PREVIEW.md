## Parcours opérateur

Ouvrir **Outils → Comparer NetBox (lecture seule)**. L'onglet apparaît **hors ligne** et n'effectue aucune requête. Saisir une origine HTTPS NetBox sans chemin ni credentials. Cocher explicitement **Autoriser une lecture réseau explicite (GET)** puis cliquer sur **Comparer maintenant**. L'absence de jeton, l'échec TLS, la panne réseau, une réponse invalide ou une pagination dangereuse produisent un code d'erreur générique, sans données partielles.

Le jeton est lu **uniquement en mémoire** dans `OPENREMOTE_NETBOX_TOKEN` au clic, jamais depuis un champ de l'interface, un argument CLI ou une URL. Il n'est pas enregistré, affiché, journalisé ou exporté. Le connecteur R73 n'autorise que `GET /api/dcim/devices/` sur HTTPS, sans redirection et avec limites strictes. L'interface n'effectue aucun polling ni connexion à l'ouverture.

### Vue comparative

| État | Signification | Comportement |
|---|---|---|
| `matched` | Nom NetBox ou IPv4 principale correspond à un hôte local unique | Observation uniquement |
| `missing_local` | Équipement NetBox sans hôte local reconnu | Aucune création automatique |
| `local_only` | Connexion locale SSH/SFTP/RDP/VNC sans équipement reconnu | Aucune suppression automatique |
| `ambiguous` | Collision de noms/IP, plusieurs connexions locales ou plusieurs candidats | Refus de choisir automatiquement |

Normalisation : noms DNS en minuscules sans point final, IPv4 CIDR NetBox comparée à l'adresse IP locale, IPv6 locales normalisées. Les connexions WEB/URL sont exclues pour éviter de traiter des URL contenant des paramètres sensibles. Les utilisateurs, tags, groupes, mots de passe, clés et références PAM ne sont jamais transmis au comparateur ni affichés. Un doublon reste **ambigu**, même si un choix semble plausible.

## Architecture

```text
Menu Outils (Qt) -> NetBoxPreviewPanel (hors ligne par défaut)
                      | consentement explicite + bouton
                      v
                   QRunnable (hors thread UI)
                      | GET-only NetBoxReadOnly (R73)
                      v
                   compare_inventory (pur, sans I/O)
                      | matched / missing_local / ambiguous / local_only
                      v
                   Signal Qt -> QTreeWidget (lecture seule)
```

Les traitements réseau s'exécutent via `QThreadPool`, pas dans le thread GUI. Le bouton est désactivé pendant la requête; aucun import, mutation du `Store`, session SSH/RDP ou tunnel n'est déclenché. Les erreurs inattendues sont expurgées en `netbox_network_unavailable` et les erreurs de contrat ont des codes stables. Le contenu d'une réponse distante n'est jamais interprété comme du code.

## Risques résiduels et prochaine étape

La correspondance nom/IP n'est pas une identité de machine vérifiée. DNS et adresses peuvent être réattribués; les collisions sont bloquées mais un nom unique peut aussi être obsolète.
