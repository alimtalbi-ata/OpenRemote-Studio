# OpenRemote Studio V31.8 — R75 : filtres locaux NetBox

**Auteur : Abdelhalim Talbi** · **24 octobre 2026** · **Évolution P1 candidate, sans qualification de production**

## Besoin métier et usage

Sur un inventaire NetBox important, retrouver immédiatement les hôtes absents et les collisions sans refaire de requête, importer de profil ni modifier les données. L'opérateur utilise « Outils → Comparer NetBox (lecture seule) », autorise explicitement la consultation HTTPS, puis filtre l'instantané déjà reçu.

## Architecture et flux

1. Le panneau Qt R74 reste **hors ligne par défaut**. Une origine HTTPS et un consentement explicite sont nécessaires avant toute requête GET.
2. Le worker existant récupère une projection NetBox bornée; le comparateur R74 construit un instantané local non destructif.
3. Le moteur pur R75 `Application/netbox_preview_filter.py` filtre en mémoire sur les états `matched`, `missing_local`, `ambiguous`, `local_only` et sur le nom d'équipement/hôte local.
4. Le tableau et le compteur « visibles/total » sont actualisés sans nouveau GET. Les compteurs globaux du comparateur restent inchangés.

## Contrôles de sécurité

- La fonction de filtrage ne lit que `status`, `device`, `local_host`. Aucun identifiant, jeton, mot de passe, tag ou note n'est projeté.
- Recherche bornée à 120 caractères, caractères de contrôle refusés, entrées et lignes malformées rejetées avec codes d'erreur stables.
- Aucun accès réseau, import, export, synchronisation ou écriture dans le moteur de filtre.
- Une collision reste ambiguë : le filtre ne la résout pas automatiquement.
- Limite : le panneau affiche des noms d'hôtes, qui restent des métadonnées potentiellement sensibles.
- Le retrait du consentement **pendant** une requête en cours ne garantit pas encore son annulation; à traiter en priorité lors de la prochaine itération.

## Tests et frontières de preuve

- 12 tests unitaires purs exécutés en laboratoire Python/POSIX : PASS (filtrage, recherche, confidentialité, validation, non-mutation).
- 2 tests Qt headless ajoutés : hors ligne sans réseau et filtrage sans second GET. Résultats Windows CI à vérifier.
- Gates Windows native et cumulative modifiés pour exécuter les tests R75.
- Aucune recette contre une API NetBox réelle, aucun essai OpenSSH tunnel réel R75, aucune capture réelle et aucun essai Windows physique indépendant.
- Aucun exécutable ni ZIP cumulatif R75 ne doit être présenté comme construit avant confirmation des artefacts GitHub Actions.
