# OpenRemote Studio — référentiel des 12 produits et couverture (V31.8)

Auteur : Abdelhalim Talbi. Statut : exigences et critères d'acceptation, **pas une attestation de fonctionnalités livrées**.

## Positionnement
Une console Windows unifiée, orientée opérateur, doit fournir un accès distant fiable et sécurisé. Les moteurs spécialisés (Ansible, Zabbix, Grafana, NetBox, Wireshark, Vault) seront intégrés via interfaces/API explicites plutôt que clonés. Chaque intégration doit rester optionnelle et dégradée proprement en absence de serveur.

## Matrice de référence et critères d'acceptation
| Référence | Cas d'usage | Choix d'architecture | Critère de qualification |
|---|---|---|---|
| MobaXterm | SSH, RDP, SFTP, terminaux, tunnels | Moteurs natifs et adaptateurs | Sessions concurrentes, transfert repris, host key vérifiée, tunnel local borné |
| Royal TS | Profils partagés, groupes, RDP/SSH/VNC | Catalogue versionné et adaptateurs protocoles | Import/export sans fuite de secrets, reconnexion, recherche rapide |
| Devolutions RDM | Coffres, credentials, audit | Références aux secrets, RBAC si multi-utilisateur | Aucune valeur de secret dans logs/export; accès tracé |
| mRemoteNG | Onglets, groupes, connexions | UX de sessions multi-protocoles | 20 sessions simulées sans blocage UI, isolation des erreurs |
| Termius | SSH moderne, snippets, clés | Profils de clés et snippets paramétrés | Fingerprint explicite, rotation contrôlée, commandes à risque confirmées |
| Windows Admin Center | Windows Server, PowerShell, services, événements | Adaptateur WinRM/PowerShell sécurisé | Authentification forte, moindre privilège, opérations lecture seule par défaut |
| Ansible | Inventaires, playbooks | Runner/API externe, prévisualisation | Dry-run/check, approbation, capture code retour et logs expurgés |
| Zabbix | Supervision et alertes | API Zabbix en lecture seule par défaut | Lien équipement-incident-session et état indisponible visible |
| Grafana | Dashboards, observabilité | Deep links/API avec contexte | Pas de token dans URL/logs, filtrage des tableaux de bord |
| NetBox | IPAM/DCIM, inventaire | Source de vérité externe, synchronisation explicite | Diff, résolution conflits, pas d'écriture silencieuse |
| Wireshark | PCAP et diagnostic réseau | Ouverture PCAP locale via outil installé | Consentement capture, taille limitée, pas de capture furtive |
| HashiCorp Vault | Secrets dynamiques, rotation | Adaptateur Vault, tokens à durée courte | TTL, révocation, zéro stockage plaintext, audit sans secret |

## Gates qualité obligatoires
1. **G0 Inventaire** : localiser pour chaque ligne code, UI, tests, docs, démonstration réelle et lacunes; classer IMPLEMENTED / PARTIAL / NOT_IMPLEMENTED / UNVERIFIED.
2. **G1 Sécurité** : host-key SSH fail-closed, coffre sans export plaintext, aucune fuite d'identifiants, timeouts et contrôle d'accès; revue de menace.
3. **G2 Fonctionnel** : scénario positif, panne réseau, annulation, reprise, concurrence, mauvaise configuration et nettoyage des ressources.
4. **G3 Intégrations** : contrats API versionnés, permissions minimales, pagination, rate limits, erreurs, offline mode et absence de dépendance imposée.
5. **G4 Windows** : CI native, tests UI, installateur/portable exécutés sur Windows, désinstallation, manifestes SHA256 et provenance binaire.
6. **G5 Documentation** : guide utilisateur et administrateur, architecture, limites, captures réelles uniquement, preuves liées au commit.

## Ordre de livraison
- P0 : SSH/RDP/SFTP/VNC, profils et onglets, host-key, tunnels, coffre, gestion des erreurs, packaging Windows.
- P1 : PowerShell/WinRM, NetBox, Vault, Ansible, Zabbix, Grafana; connecteurs découplés et lecture seule par défaut.
- P2 : PCAP/Wireshark, automatisation avancée, tableaux de bord consolidés et importeurs supplémentaires.

## Décision d'architecture
Ne pas déclarer une parité fonctionnelle avec les douze références sans une matrice de preuves exécutable. Chaque cycle horaire sélectionne une lacune P0/P1 démontrable, implémente code + tests + docs sur branche dédiée, qualifie la CI, puis actualise ce référentiel. Ne pas fusionner automatiquement dans main.
