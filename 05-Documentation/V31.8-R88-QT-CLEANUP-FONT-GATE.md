# V31.8 R88 — Qt: fermeture sûre et lisibilité des captures Windows

Auteur : Abdelhalim Talbi. Date : 24 octobre 2026. PR draft, non fusionnée.

## Incident P0 : fermeture prématurée d'un onglet
Le panneau SSH Qt utilisait la seule phase `closed/failed/disconnected` pour arrêter son timer et déclencher les callbacks de fermeture du parent. Si un contrôleur signalait une phase terminale alors que des ressources étaient encore en drainage, l'onglet pouvait disparaître avant la confirmation de nettoyage. R88 exige désormais **à la fois** une phase terminale et `is_shutdown_complete() == True`. Sinon, le panneau garde le timer actif, bloque la reprise et conserve les callbacks en attente. Les messages restent expurgés.

## Incident UX P1 : capture Qt illisible
La capture Windows R87 (Qt `offscreen`) rendait des carrés pour les lettres, y compris ASCII. Sauver un PNG n'attestait donc pas la lisibilité. `Application/qt_font_render_gate.py` charge explicitement une police **déjà installée sur le runner Windows** (Segoe UI, Arial, Tahoma ou Verdana), sans copier ni distribuer aucun fichier de police. Le contrôle exige la présence des glyphes A/W/é et un rendu raster distinct de A et W. La capture est refusée si ces conditions échouent. Le nouveau nom de preuve est `Binary/Qualification/qt-tunnel-r88-offline.png` et son fichier SHA-256 adjacent.

Cette correction concerne la **capture Qt offscreen**; elle ne prouve pas encore la lisibilité sur un poste Windows physique. Le mode de capture reste hors ligne, sans connexion ni identifiant.

## Tests et qualification
`Application/tests/test_tunnel_cleanup_barrier_qt_r88.py` définit trois tests avec contrôleur synthétique : callback différé jusqu'au drainage, reprise interdite avant drainage, callback unique. Le workflow `windows-native.yml` exécute explicitement ces tests avec PySide6, puis la capture soumise au contrôle de glyphes. Les résultats doivent être relevés dans la CI du commit exact; les tests ne prouvent pas un SSH réel. Le workflow OpenSSH conserve ses scénarios réels existants.
