# V31.8 — Contrat de publication cumulative Windows

Auteur : Abdelhalim Talbi

## Statut

Document de conception. Aucun binaire Windows ni test d'interface n'est certifié par ce document.

## Archive attendue

`OpenRemote-Studio-V31.8-Windows-Cumulative.zip` doit contenir :

- `01-Application/` : installateur Windows et version portable réellement construits.
- `02-Compilation/` : scripts et instructions de compilation.
- `03-Sources/` : snapshot des sources correspondant au commit compilé.
- `04-Tests-et-Qualification/` : rapports de tests, journaux, résultats et limites.
- `05-Documentation/` : guides Word/PDF actualisés, captures réelles identifiées.
- `06-Historique/` : changelog et notes de migration.
- `07-Manifestes/` : provenance, inventaire et empreintes SHA-256.

## Provenance minimale

`07-Manifestes/provenance.json` :

```json
{
  "commit": "0123456789abcdef0123456789abcdef01234567",
  "windows_build_run": "EXAMPLE-ONLY",
  "version": "31.8"
}
```

Les valeurs ci-dessus sont des exemples fictifs, pas des preuves de qualification.

## Règles de publication

1. Compiler depuis un checkout propre du SHA exact indiqué dans le manifeste.
2. Enregistrer l'identifiant réel du run Windows et les versions des outils.
3. Exécuter les tests de non-régression et la recette native.
4. Construire les livrables Installer et Portable, vérifier leurs démarrages.
5. Capturer les interfaces réellement exécutées ; déclarer toute capture manquante.
6. Générer la documentation Word/PDF à partir de la version effective.
7. Assembler l'archive et calculer ses empreintes.
8. Exécuter `python 02-Compilation/verify_cumulative_v318.py <zip> --expected-commit <sha>`.
9. Publier seulement si toutes les étapes obligatoires sont PASS.

## Limites actuelles

Le vérificateur V31.8 contrôle la structure, la sécurité élémentaire de l'archive et la cohérence du SHA attendu. Il ne prouve pas, à lui seul, que les binaires proviennent de ce commit, ni que l'interface Windows fonctionne. L'intégration d'un manifeste signé, d'un inventaire de fichiers et d'une recette SFTP bout en bout reste à réaliser.
